# Dependensi pihak ketiga

| Paket | Lisensi | Penggunaan |
| --- | --- | --- |
| Laravel framework | MIT | Backend, auth session, Blade, Eloquent/query builder, validation |
| chillerlan/php-qrcode | MIT | Generator QR SVG backend |
| html5-qrcode 2.3.8 | Apache-2.0 | Scanner kamera/file di browser; bundle dan LICENSE lokal |
| Tailwind CSS 3.4.17 | MIT | CSS UI hasil build; LICENSE lokal |

Versi transitive dependency direkam di composer.lock dan package-lock.json. Source upstream serta lisensi dependensi PHP tersedia setelah composer install. File public/assets/html5-qrcode.min.js didistribusikan tanpa mengubah decoder.
